## Comparing

Right-click a plot, choose **Select for Visual Diff**, then right-click another
and choose **Compare Visually with Selected**. It works on two folders too, and
pairs the files inside them by name.

To compare against an earlier version of the same plot, select it and run
**plotExcel: Compare Selected with Revision…**, then pick a commit.

The comparison is a layout file like any other, so if the pages do not line up
you can shift one side down by hand and render again.
