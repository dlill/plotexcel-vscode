## What always works

PDF and image plots render with nothing installed.

## What depends on this computer

| Plots from | Needs |
|---|---|
| Word, PowerPoint, Excel | Microsoft Office, or LibreOffice |
| HTML pages | Microsoft Edge, Google Chrome, or another Chromium browser |
| An earlier committed version | git |

A plot whose tool is missing still gets a place in the workbook — the cell
carries a picture that says what to install, and everything else renders
normally.
